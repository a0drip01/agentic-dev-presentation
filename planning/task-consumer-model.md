# Task: Design Consumer Subscription Model

## Goals
- Create a new Django model to track consumers and their subscription tags.

## Steps
1. Define model fields:
   - Consumer ID (unique)
   - Tags (provider, room number, etc.)
   - Registration timestamp
2. Add model to `core/models.py`
3. Create and run migrations
4. Document model usage

## Deliverables
- Model code in `core/models.py`
- Migration files
- Documentation in planning folder
